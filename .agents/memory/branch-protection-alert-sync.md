---
name: وضوح مزامنة تنبيه حماية الفروع
description: قاعدة التعامل مع فشل GitHub API أثناء دورة حياة تنبيه حماية الفرع.
---

يجب أن يكون فشل قراءة أو إنشاء أو تحديث تنبيه حماية الفرع فشلاً نهائياً واضحاً في workflow، مع تمييزه نصياً عن فشل فحص حماية الفرع نفسه.

**Why:** نجاح الفحص لا يثبت أن التنبيه وصل إلى فريق التشغيل، وفشل المزامنة الصامت أو الملتبس قد يوحي بأن الحالة عولجت بينما لا يوجد تنبيه موثوق.

**How to apply:** سجّل العملية التي فشلت وسبب GitHub API، ثم مرّر النتيجة إلى خطوة فشل صريحة قابلة للاكتشاف من حالة التشغيل؛ ينطبق ذلك على إنشاء التنبيه وتحديثه وإغلاقه وقراءة قائمة التنبيهات.
