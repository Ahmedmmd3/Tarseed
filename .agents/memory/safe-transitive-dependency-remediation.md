---
name: إصلاح الاعتمادات العابرة بأمان
description: قاعدة للتعامل مع ثغرة في اعتماد عابر عندما لا يعلن الأب بعد دعمه للإصدار المصحح.
---

حدّث الحزمة الأب إلى إصدار يعلن الاعتماد الآمن أولاً. لا تستخدم override عاماً إذا كان الإصلاح يخص مساراً واحداً؛ احصره في الأب والإصدار المتأثر، واستخدم package extension فقط عندما تكون بيانات التوافق المنشورة قديمة.

**Why:** قد يجعل override العام التدقيق الأمني أخضر بينما يفرض إصدارات رئيسية غير مدعومة على آباء آخرين. التوافق النظري لا يكفي عندما تتجاوز قيود الحزمة المنشورة.

**How to apply:** افحص مسار `why` لكل ثغرة، حدّث الآباء الممكنة، ثم اختبر السلوك الذي يستدعي الاعتماد فعلياً—مثل migration أو build plugin أو multipart—قبل اعتماد أي استثناء محدود.
