---
name: تجميع اختبارات API
description: قيد بيئة عند تجميع اختبار Node يستورد تطبيق API ومساحة عمل قاعدة البيانات.
---

يجب أن يوفّر ملف اختبار ESM المجمّع `require` عبر `createRequire` عند تضمين التطبيق وقاعدة بيانات PostgreSQL.

**Why:** مكتبة `pg` تعتمد بعض وحدات CommonJS عبر تحميل ديناميكي؛ تضمينها في مخرجات ESM بلا هذا الجسر يفشل قبل تنفيذ الاختبارات.

**How to apply:** عند إضافة اختبار API يحمّل التطبيق وطبقة البيانات مع `esbuild`، أضف banner قصيراً يعرّف `require = createRequire(import.meta.url)`، واحفظ الناتج المؤقت ضمن مجلد الاختبارات لكي تحل Node الاعتمادات الخارجية من المشروع.
