---
name: سياسة فحوصات CI المصفوفية
description: القرار الخاص بالتعامل مع أسماء فحوصات وظائف GitHub التي تستخدم strategy.matrix.
---

حارس تطابق فحوصات CI يتعامل مع وظائف `strategy.matrix` كحالة غير مدعومة ويرفضها بدلاً من تخمين أسماء الفحوصات التي يوسّعها GitHub.

**Why:** اسم الوظيفة الأساسي لا يطابق بالضرورة سياقات الفحص التي يراها GitHub لكل عنصر في المصفوفة، وتخمينها قد يجعل إعداد الحماية يبدو صحيحاً محلياً ثم يمنع الدمج.

**How to apply:** عند دعم المصفوفات لاحقاً، يجب أولاً مطابقة سلوك تسمية GitHub واختباره للاسم المعلن والاسم الاحتياطي، ثم تحديث الحارس وإعداد فحوصات الفرع معاً.
