---
name: سياسة فحوصات CI المصفوفية
description: القرار الخاص بالتعامل مع أسماء فحوصات وظائف GitHub التي تستخدم strategy.matrix.
---

حارس تطابق فحوصات CI يوسّع وظائف `strategy.matrix` ذات القيم الثابتة إلى أسماء الفحوصات التي تظهر في GitHub: يقيّم الاسم المعلن من تعبيرات `matrix.*`، أو يكوّن الاسم الاحتياطي من معرّف الوظيفة وقيم المحاور بترتيبها. أما المصفوفات التي تستمد قيماً وقت التشغيل من تعبير GitHub (مثل مخرجات وظيفة سابقة) فلا تُوسّع ولا تُخمن أسماؤها.

**Why:** يجب أن تطابق الفحوصات المطلوبة الأسماء الموسعة لكل تركيبة ثابتة، وإلا قد يبدو إعداد الحماية سليماً محلياً بينما يفقد GitHub فحصاً مطلوباً ويمنع الدمج. لا يمكن معرفة أسماء التركيبات الديناميكية قبل أن يوسّعها GitHub، وتخمينها قد يفرض فحصاً غير موجود أو يوقف دمج سير عمل صالح.

**How to apply:** حافظ على قيم المحاور الثابتة صريحة وقابلة للتوسيع في الحارس، وحدث قائمة الحماية مع كل اسم ناتج. لا تضع أسماء فحوصات المصفوفات الديناميكية في الحماية؛ إذا كانت نتائجها إلزامية، أضف وظيفة تجميعية غير مصفوفية باسم ثابت واجعلها الفحص المطلوب. تُحل أيضاً دموج YAML في تعريف الوظيفة، والمصفوفة، و`include` و`exclude` مع أولوية القيم المحلية.
