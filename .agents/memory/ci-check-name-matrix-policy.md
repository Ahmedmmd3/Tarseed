---
name: سياسة فحوصات CI المصفوفية
description: القرار الخاص بالتعامل مع أسماء فحوصات وظائف GitHub التي تستخدم strategy.matrix.
---

حارس تطابق فحوصات CI يوسّع وظائف `strategy.matrix` ذات القيم الثابتة إلى أسماء الفحوصات التي تظهر في GitHub: يقيّم الاسم المعلن من تعبيرات `matrix.*`، أو يكوّن الاسم الاحتياطي من معرّف الوظيفة وقيم المحاور بترتيبها.

**Why:** يجب أن تطابق الفحوصات المطلوبة الأسماء الموسعة لكل تركيبة، وإلا قد يبدو إعداد الحماية سليماً محلياً بينما يفقد GitHub فحصاً مطلوباً ويمنع الدمج.

**How to apply:** حافظ على قيم المحاور صريحة وقابلة للتوسيع في الحارس، وحدث قائمة الحماية مع كل اسم ناتج. تُحل أيضاً دموج YAML في تعريف الوظيفة، والمصفوفة، و`include` و`exclude` مع أولوية القيم المحلية.
