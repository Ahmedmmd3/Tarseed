---
name: صلاحيات فحص حماية الفروع
description: قيد صلاحيات GitHub Actions عند قراءة إعداد حماية فرع من API.
---

لا تضف `administration` إلى كتلة `permissions` في GitHub Actions؛ صيغة workflow لا تقبل هذا المفتاح. قراءة حماية الفرع تتطلب اعتماداً خارج المستودع لديه صلاحية إدارة قراءة.

**Why:** صلاحية REST لقراءة حماية الفرع ترتبط بإدارة المستودع، بينما مفاتيح `permissions` المتاحة للـ workflow لا تتضمن `administration`. إضافة المفتاح تجعل ملف workflow غير صالح، ورمز Actions الافتراضي لا يكتسب صلاحية الإدارة.

**How to apply:** استخدم أقل صلاحيات workflow صالحة واعتمد على رمز مؤقت من اعتماد مُدار خارج المستودع؛ عند 403 راجع صلاحياته، ولا تضف رمزاً دائماً أو مفتاحاً غير مدعوم إلى المستودع.
