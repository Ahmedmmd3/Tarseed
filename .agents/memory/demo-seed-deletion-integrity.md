---
name: حذف البذور التجريبية بأمان
description: قواعد حذف بيانات البداية التجريبية دون إعادتها أو كسر مراجع بيانات المستخدم.
---

يجب أن يكون تحديث الجلسة قراءة فقط؛ لا تربطه بتهيئة تلقائية تعيد إنشاء بيانات تجريبية أو افتراضية حُذفت عمداً. وقبل حذف سجل تجريبي، افحص داخل المعاملة مراجع السجلات غير التجريبية إليه، وارفض الحذف إذا سيترك مرجعاً معلقاً.

**Why:** قد يبدو الحذف ناجحاً ثم تعيد عملية refresh الحسابات فوراً، أو قد تبقى قيود وتسويات المستخدم مرتبطة بحساب أو قيد تجريبي محذوف فتختفي آثارها من التقارير.

**How to apply:** استخدم وسماً موحداً لكل سجلات البذور، افحص مفاتيح المراجع الفعلية قبل الحذف، ارفع جيل البيانات ذرياً، واجعل تحميل الجلسة لا ينشئ سجلات.
