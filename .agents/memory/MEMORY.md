- [سلامة مخزون المواقع](multi-location-inventory-integrity.md) — اعتبر إجمالي المنتج قيمة مشتقة من أرصدة المواقع، ولا تعدّله كرصيد مستقل.
- [استعادة الجلسة المشتركة](shared-session-recovery.md) — فشل الاتصال المؤقت لا يبرر مسح لقطة السجل المحلية.
- [سلامة طابور المزامنة](offline-sync-idempotency.md) — أي إنشاء مؤجل يجب أن يحمل معرّف عملية فريداً يطبّقه الخادم ذرياً.
- [سلامة استعادة بيانات المنشأة](erp-backup-restore-integrity.md) — الاستعادة تزيد جيلاً ذرياً وتتحقق من لقطة الإقفال مقابل السجل المعاد قبل الحذف.
- [سلامة إتمام البيع](pos-checkout-integrity.md) — تعامل مع سلة نقطة البيع كمعاملة خادم واحدة مرتبطة بمعرّف يمنع التكرار.
- [سياسة فحوصات CI المصفوفية](ci-check-name-matrix-policy.md) — حارس الحماية يرفض وظائف matrix ما لم تُدعَم أسماء GitHub الموسّعة صراحةً.
- [جاهزية إنتاج الفوترة السعودية](zatca-production-readiness.md) — لا يفتح إنتاج الهيئة قبل اختبار الامتثال الرسمي وسجل إرسال ذري.
- [ترحيل مخطط الإنتاج](managed-schema-publish.md) — تغييرات مخطط PostgreSQL المُدار تصل للإنتاج عبر النشر، لا عبر DDL وقت التشغيل.
