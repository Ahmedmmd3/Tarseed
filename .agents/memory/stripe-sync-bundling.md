---
name: مزامنة Stripe والتجميع
description: قيد وقت التشغيل لمكتبة stripe-replit-sync داخل خادم API المجمع.
---

عند استخدام `stripe-replit-sync`، يجب أن تبقى الحزمة خارج تجميع esbuild في خادم API.

**Why:** تعتمد المكتبة على موقعها في نظام الملفات للعثور على ملفات ترحيل مخطط `stripe`. تجميعها داخل ملف الخادم يجعل الترحيلات تبدو ناجحة دون إنشاء الجداول اللازمة.

**How to apply:** عند تعديل إعدادات بناء خادم API أو ترقية مكتبة المزامنة، تأكد من بقاء `stripe-replit-sync` (وStripe) ضمن الحزم الخارجية، ثم تحقق من وجود جداول مخطط `stripe` بعد إعادة تشغيل الخدمة.
