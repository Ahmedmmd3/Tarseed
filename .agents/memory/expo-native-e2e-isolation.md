---
name: عزل اختبارات Expo الأصلية
description: قاعدة تشغيل اختبارات التطبيق الأصلي دون ملامسة API أو خدمات إنتاجية.
---

اختبارات Expo الأصلية السوداء تستخدم Maestro مع Fixture HTTP محلي، ويجب أن يرفض
أمر التشغيل البدء ما لم يكن عنوان API عنوان محاكي محلياً صريحاً.

**Why:** سلوك SecureStore ودورة التطبيق والتنقل الأصلي لا يثبته اختبار الويب، وفي الوقت
نفسه لا يجوز أن تُنشئ اختبارات المزامنة سجلات حقيقية أو ترسل آثاراً إلى خدمات خارجية.

**How to apply:** عند توسيع تدفقات الهاتف، أضف المسار إلى Fixture المحلي وتحقق من الأثر
المسجل فيه. حافظ على فشل مزامنة حتمي يمكن إعادته، وشغّل التدفق على Android Emulator أو
iOS Simulator بدلاً من استبداله بمحاكاة متصفح.
