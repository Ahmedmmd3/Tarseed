---
name: دفع GitHub Actions من Replit
description: قيد صلاحيات OAuth عند دفع ملفات GitHub Actions، والمسار الآمن لتجاوزه.
---

قد يرفض GitHub دفعاً من Replit يحتوي ملفات تحت `.github/workflows` برسالة نقص صلاحية `workflow`، حتى لو كان المستودع البعيد فارغاً وكانت صلاحية `repo` متاحة.

**Why:** إعادة ربط موصل GitHub لا تفيد إذا كانت مجموعة الصلاحيات التي يطلبها الموصل لا تتضمن `workflow`. كما أن deploy key يُنشأ عبر OAuth نفسه قد يبقى خاضعاً لقيد التطبيق.

**How to apply:** أثبت أولاً أن المستودع البعيد فارغ أو افحص تاريخه. إن لم تتوفر صلاحية `workflow`، ولّد مفتاح SSH مؤقتاً واطلب من مالك المستودع إضافته يدوياً مع الكتابة؛ ادفع عبر SSH ثم احذف المفتاح من GitHub والبيئة فوراً.
