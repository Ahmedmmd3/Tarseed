---
name: تصدير PDF العربي
description: يوضح طريقة موثوقة لتوليد ملفات PDF عربية من المتصفح دون صفحات بيضاء.
---

ارسم العناوين والجداول العربية مباشرة باستخدام Canvas ثنائي الأبعاد، ثم أدرج كل صفحة كصورة داخل jsPDF.

**Why:** مسار `jsPDF.html()` مع عناصر HTML المخفية أو خارج الشاشة نجح في إنشاء الملفات وعدد الصفحات، لكنه أنتج صفحات بيضاء بالكامل حتى عندما بدا التنزيل ناجحاً.

**How to apply:** في أي تصدير PDF عربي داخل الويب، اختبر الناتج بتحويل صفحة PDF إلى صورة والتأكد بصرياً من وجود محتوى، ولا تعتبر حدث التنزيل أو حجم الملف وحدهما دليلاً كافياً.

أضف طبقة نصية غير مرئية فوق صورة Canvas إذا كان التقرير يحتاج إلى التحقق الآلي من الصفوف أو البحث والنسخ داخل قارئ PDF.

**Why:** صورة Canvas وحدها لا تنتج نصاً قابلاً للاستخراج، لذلك لا يكشف فحص البكسلات فقدان صف أو تغيّر ترتيبه.

**How to apply:** اجعل الطبقة النصية في مساحة بيضاء وبصيغة لا تغيّر العرض، واستخدم علامات فريدة قابلة للاستخراج في اختبار PDF للتحقق من الصفحة المتوقعة لكل صف.
