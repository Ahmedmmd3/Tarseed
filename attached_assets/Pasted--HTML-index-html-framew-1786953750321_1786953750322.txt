أنشئ تطبيق ويب محاسبة وكاشير متكامل باسم "وضوح" بملف HTML واحد فقط (index.html).
لا تستخدم أي framework خارجي عدا Dexie.js من unpkg.

═══════════════════════════════
اللغة والاتجاه: عربي كامل RTL
اللون الرئيسي: #1D9E75
الشعار: مربع أخضر مع علامة صح بيضاء + كلمة "وضوح"
═══════════════════════════════

── التقنية ──
- Dexie.js من unpkg للتخزين المحلي (Offline-First)
- IndexedDB لكل البيانات — يعمل بدون إنترنت
- localStorage لحفظ جلسة المستخدم
- مؤشر حالة الاتصال (متصل/غير متصل)
- ملف واحد فقط: HTML + CSS + JS في index.html

── Auth ──
- تسجيل حساب: اسم المشروع + إيميل + كلمة مرور
- تسجيل دخول محفوظ في IndexedDB
- حفظ الجلسة في localStorage

── Sidebar Navigation ──
- لوحة التحكم
- الكاشير (نقطة البيع)
- المنتجات
- الفواتير
- المصاريف
- العملاء
- التقارير
- تسجيل خروج
- مؤشر اتصال أسفل الـ sidebar

═══════════════════════════════
1. لوحة التحكم
═══════════════════════════════
- 4 KPI cards: إجمالي الإيرادات، فواتير معلقة، إجمالي المصاريف، صافي الربح
- آخر 4 فواتير
- آخر 4 مصاريف
- آخر 4 مبيعات كاشير

═══════════════════════════════
2. وضع الكاشير (نقطة البيع) — الأهم
═══════════════════════════════
واجهة مقسمة:
- يمين: حقل إدخال الباركود (autofocus دائماً)
- يسار: سلة المشتريات

تفاصيل الباركود:
- حقل input مخفي دائماً في focus يستقبل باركود من جهاز USB
- عند scan: يبحث عن المنتج في قاعدة البيانات بالباركود
- إذا وجد: يضيفه للسلة تلقائياً مع صوت beep
- إذا لم يجد: يظهر رسالة "منتج غير موجود — هل تريد إضافته؟"
- يمكن أيضاً البحث يدوياً بالاسم أو الباركود

السلة:
- قائمة المنتجات المضافة مع الكمية والسعر
- زر + و - لتعديل الكمية
- زر حذف لكل منتج
- إجمالي فرعي، ضريبة، خصم، إجمالي نهائي
- اختيار العميل (اختياري)
- اختيار طريقة الدفع: نقداً / بطاقة / آجل

إتمام البيع:
- زر "إتمام البيع" كبير وواضح
- عند الضغط: ينشئ فاتورة تلقائياً
- ينقص المخزون تلقائياً
- يظهر ملخص البيع مع إمكانية الطباعة
- يصفر السلة ويعود لوضع الكاشير

═══════════════════════════════
3. المنتجات (كتالوج)
═══════════════════════════════
- إضافة منتج: اسم، باركود، سعر البيع، سعر الشراء، المخزون، الفئة، وحدة القياس
- عرض جدول المنتجات مع البحث
- تعديل وحذف
- تحذير عند نفاد المخزون (أقل من 5)
- فلترة بالفئة

═══════════════════════════════
4. الفواتير
═══════════════════════════════
- إنشاء فاتورة يدوية مع:
  - اختيار عميل
  - تاريخ وتاريخ استحقاق
  - بنود متعددة (وصف/كمية/سعر)
  - ضريبة القيمة المضافة %
  - خصم %
  - حساب إجمالي تلقائي
  - ملاحظات
- حالات: معلقة / مدفوعة / متأخرة
- عرض الفاتورة كاملة
- تحديد كمدفوعة
- طباعة
- حذف
- فلترة بالحالة

═══════════════════════════════
5. المصاريف
═══════════════════════════════
- إضافة مصروف: وصف، مبلغ، فئة، تاريخ، طريقة دفع، ملاحظات
- الفئات: إيجار، رواتب، مشتريات، مرافق، تسويق، نقل، صيانة، أخرى
- عرض جدول المصاريف
- حذف

═══════════════════════════════
6. العملاء
═══════════════════════════════
- إضافة عميل: اسم، هاتف، إيميل، عنوان
- عرض إجمالي مشتريات كل عميل
- حذف

═══════════════════════════════
7. التقارير
═══════════════════════════════
- 4 KPI cards للشهر الحالي
- تفاصيل المصاريف بالفئات
- أكثر المنتجات مبيعاً (top 5)
- ملخص المبيعات اليومية لآخر 7 أيام
- زر طباعة

═══════════════════════════════
التصميم
═══════════════════════════════

- Modals للإضافة والتعديل
- جداول بـ hover effect
- Badges ملونة للحالات
- متجاوب مع الموبايل

- صوت beep عند scan الباركود ناجح (AudioContext)
- صوت مختلف عند منتج غير موجود
